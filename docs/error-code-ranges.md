# 错误码登记表

> 本文件是错误码的**唯一登记处**（对应 `CLAUDE.md` 6.4.2）：
> - **系统段 `1xxxx` / 校验段 `3xxxx`**：全系统统一固定码值（见 §1），各 `{system}-common` 对齐维护同一套；
> - **业务段 `2xxxxx`**：系统号在此登记（见 §2），业务序号在各系统枚举内分配。
>
> 禁止跨系统同码不同义。

---

## 1. 系统段 / 校验段固定码值（全系统统一）

> 各 `{system}-common` 必须原样维护下表的码值与语义；新增或调整须**先改本表**再改代码。
> HTTP 分流场景见 `CLAUDE.md` 5.3。

| code | 语义 | HTTP |
|------|------|------|
| `10001` | 未认证（未登录 / Token 无效） | 401 |
| `10002` | 无权限 | 403 |
| `10003` | 请求过于频繁（限流） | 429 |
| `10004` | 系统异常 | 5xx |
| `30001` | 参数校验失败（字段细节放 `data`） | 200 |

---

## 2. 业务段（`2xxxxx`）系统号登记

### 2.1 规则

- 业务错误码格式：`2` + 系统号（2 位）+ 业务序号（3 位），共 6 位（`number`）。
- 系统号从 `01` 起按登记顺序递增分配；一经分配不再变更。
- 系统下线后其系统号**作废不复用**。
- 业务序号（3 位）由各系统在自己的 `XxxErrorCodeEnum` 内分配，不进本表。
- 新增业务错误码前，先在本表确认本系统号已登记，再进枚举（见 `CLAUDE.md` 6.4.2）。
