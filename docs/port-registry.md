# 端口登记表（port-registry）

> **唯一端口登记与规划处**（对应 `CLAUDE.md` 文档分工）。
> - 查/改**端口、协议、入口路径**看本文件；
> - 账密与连接串看 [`test-env.md`](test-env.md)；
> - **禁止**把端口写进 `CLAUDE.md`。
>
> 新增/调整端口：先改本表，再改各系统 `application-*.yml` / `vite.config.ts` / `deploy/`，并同步 `test-env.md` 中的接入说明。

## 1. 约定端口（规划基线）

> 本地、测试默认按下表占用；生产由部署环境覆盖时须在备注登记，并保证不与本表冲突。

### 1.1 用户中心（scaffold-user-center）

| 组件 | 类型 | 端口 | 协议 | 对外入口 | 网络边界 | 备注 |
|------|------|------|------|----------|----------|------|
| user-admin | 前端 | **5173** | http | Vite dev `http://localhost:5173` | 本机/办公网 | 生产由 Nginx 托管静态 |
| user-gateway | 后端网关 | **8173** | http | `/api/**` | 经 Nginx 反代 | 用户中心唯一对外应用入口 |
| user-service | 业务服务 | **18173** | http | `/api/**`、`/internal/**` | 仅内网/服务间 | 网关路由下游；`/internal` 不进网关 |

### 1.2 统一认证中心（unified-auth-center）

| 组件 | 类型 | 端口 | 协议 | 对外入口 | 网络边界 | 备注 |
|------|------|------|------|----------|----------|------|
| auth-portal | 前端 | **5174** | http | Vite dev `http://localhost:5174` | 本机/办公网 | 登录页；代理 `/login` `/api` `/oauth2` |
| auth-admin | 前端 | **5175** | http | Vite dev `http://localhost:5175` | 本机/办公网 | 运营后台；代理 `/login` `/api` `/oauth2` |
| auth-service | 后端单体 | **9080** | http | `/login` `/oauth2/**` `/.well-known/**` `/api/v1/**` | 经 Nginx 反代 | **无网关**；纯网关鉴权的例外（自管登录） |

### 1.3 中间件（测试/本地共用 192.168.99.100）

| 组件 | 端口 | 协议 | 备注 |
|------|------|------|------|
| MySQL | **3306** | tcp | 库：`user_db`、`auth_db` 等 |
| Redis | **6379** | tcp | user 用 DB2、auth 用 DB3（见 test-env） |
| Nacos | **8848** | http | 控制台/开放 API |
| Nacos gRPC | **9848** | grpc | 客户端注册/配置（= 8848+1000） |
| MinIO | **9000** | http | S3 兼容（如启用文件服务） |

### 1.4 端口分配规则

| 区段 | 用途 |
|------|------|
| 5170–5199 | 本地前端 Vite dev |
| 8170–8199 | 系统网关 / 对外 BFF |
| 9080–9099 | 无网关单体（如认证中心） |
| 18170–18199 | 业务微服务（仅内网） |
| 3306 / 6379 / 8848 / 9848 / 9000 | 中间件固定口 |

新增系统：前端从 **5176** 起递增；网关从 **8174** 起；业务服务从 **18174** 起。登记本表后方可写入配置。

## 2. 代理关系（本地 dev）

| 前端 | 代理前缀 | 目标 |
|------|----------|------|
| user-admin:5173 | `/api` | `http://127.0.0.1:8173`（user-gateway） |
| auth-portal:5174 | `/login` `/api` `/oauth2` | `http://127.0.0.1:9080`（auth-service） |
| auth-admin:5175 | `/login` `/api` `/oauth2` | `http://127.0.0.1:9080`（auth-service） |

生产：浏览器 → Nginx（静态）→ 网关或 auth-service（见 `deploy/nginx/`）。禁止把「本地 Vite 直连」当作生产拓扑。
