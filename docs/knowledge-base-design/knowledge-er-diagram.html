知识库（blog_db · knowledge_* 表）· ER 图

与 knowledge-base-design.md §6 草案同步 · 5 张 MySQL 知识库表 + ES index(knowledge_chunk_v1) + 3 个跨域引用（blog_db 既有表 / 用户 / 云 API）· 审计字段 5 列未画入（全表齐套）· knowledge_* 表归属 blog_db（Q5 已裁决合并；MySQL 存业务字段真相源），向量+content 镜像存 ES index（dense_vector kNN + BM25 + RRF）

主键 PK 逻辑关联（无物理外键） 业务字段 外部既有表（跨库/跨系统） 外部服务（云 API / OSS）

口径：表结构以 knowledge-base-design.md §6 为唯一源；无物理外键（逻辑关联，应用层维护）；主键 16 位发号（id 对外 String）；审计字段全表齐套未画。
