保存草稿：put draft 对象 + 登记 sys_file(ARTICLE_DRAFT) + detail.draft_file_id
发布：登记 sys_file(ARTICLE_LIVE) + detail.content_file_id ← 线上；用户端才切换
保存草稿：PUT …/content mode=draft → 只写 draft_* · status 不变 · 已发布文用户端仍读旧 object_key
发布：POST …/publish → draft 提升为 object_key · status=1 · 用户端才切换
放弃草稿：DELETE …/draft · 线上版保持不变
