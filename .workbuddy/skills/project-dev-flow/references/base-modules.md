# 项目基础内容模块清单（路线 A 询价与搭建依据）

> 用法：路线 A 中**先向用户逐项确认**（增/删/改），锁定清单后再搭建。每个模块注明"必备内容"——搭建时缺一项就不算完成。

## 询价顺序（先问，再做）

1. 出示下表默认清单，请用户逐项确认：**做 / 不做 / 改造**。
2. 统一认证中心走**条件判定**（见下），不默认做。
3. 用户补充的其他基础模块（如消息通知、文件上传、字典管理）按同格式追加。
4. 锁定清单登记进 CLAUDE.md（模块 → 代码落点，按 §目录结构），然后按依赖顺序搭建。

## 模块清单

### 1. RBAC 框架（默认必做）

| 项 | 内容 |
|---|---|
| 范围 | 用户、角色、权限（菜单/按钮/接口资源）的管理与鉴权 |
| 库表 | 用户表、角色表、权限/资源表、用户-角色、角色-权限 关联表 |
| 接口 | 用户/角色/权限 CRUD、角色授权、用户授权 |
| 功能点 | 接口鉴权（注解或中间件，未授权拒绝）、前端路由/按钮级权限控制、管理页面 |
| 要点 | 密码加密存储；超级管理员与数据隔离口径需用户确认（进待裁决） |

### 2. 登录日志（默认必做）

| 项 | 内容 |
|---|---|
| 范围 | 每次登录行为留痕：成功/失败、账号、IP、设备/UA、时间 |
| 库表 | 登录日志表 |
| 功能点 | 登录流程中埋点（成功与失败都记）、分页查询接口、管理页面、保留期限策略（问用户） |

### 3. 操作日志（默认必做）

| 项 | 内容 |
|---|---|
| 范围 | 写操作留痕：谁、何时、对什么资源、做了什么、结果如何 |
| 库表 | 操作日志表 |
| 功能点 | 声明式埋点（注解/切面/拦截器，标注在写接口上自动记录）、分页查询接口、管理页面、敏感字段脱敏口径（问用户） |
| 要点 | 与登录日志分开存储，不复用一张表 |

### 4. 统一认证中心（条件选做——不默认做）

**条件判定（先问再定）**：

| 问 | 答"是"才做 |
|---|---|
| 是否存在多个系统需要统一登录？ | 单系统项目不做 |
| 是否需要跨系统 token 互认/单点登录？ | |
| 是否已有第三方 IdP（企业微信/钉钉/OAuth2 服务商）要求对接？ | 有则优先对接，不自建 |

**确认需要后的选型（与用户共同拍板，写入 CLAUDE.md）**：

| 方案 | 适用 |
|---|---|
| 自建认证中心（JWT 签发/校验/刷新/登出） | 自有多个内部系统 |
| 对接标准协议（OAuth2 / OIDC / SAML） | 已有 IdP 或第三方要求 |
| 轻量共享（同域 Cookie/共享缓存会话） | 少量同域内部系统 |

**必备内容**：登录/登出、token 签发与校验、刷新机制、用户信息接口、其他系统接入文档。

## 搭建顺序（依赖驱动）

RBAC（含认证基础）→ 登录日志 → 操作日志 → 统一认证中心（如确认做）。

认证中心若做，则 RBAC 的登录部分挂接到认证中心，避免两套登录并存。
