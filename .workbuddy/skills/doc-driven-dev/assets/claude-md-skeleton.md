## 7. 协作红线（AI 硬性要求）

1. 不可逆操作（删表、删分支、覆盖文件）先征询确认。
2. 不擅自修改 proposal / specs / design 制品定义。
3. 不加未要求的功能，不扩大改动范围，改动取最小集。
4. 修 bug 必先看报错/日志/traceId，定位根因后再最小修改。
5. 先确认真实契约（代码/Swagger），不凭推导实现接口/枚举。
