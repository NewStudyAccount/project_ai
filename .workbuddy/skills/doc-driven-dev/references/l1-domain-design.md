# L1 领域设计三件套模板

> L1 = 领域设计层，载体 `docs/<domain>/`。写业务规则、状态机、库表契约、接口契约、原型；不写实现代码、生产密钥、端口账密、依赖版本、稳定契约口径（指针到 L0）。
> 复制 `assets/l1-starter/` 四个模板起步，按本文件填充。

## 0. README（索引页）

必备元素：

1. **文档职责表**（含状态列：设计中/已评审/已实施）
2. **实施状态**
3. **阅读顺序**（如：business → table → api）
4. **效力顺序**：正文 > 可视化（HTML/ER 图）；库表冲突以 table-design 为准
5. **范围一句话**
6. **裁剪取值登记**（对通用设计文档只登记"本系统取值 + 相对默认的差异"）
7. **相关既有材料**（指针表，不复制内容）

## 1. business-design.md（业务逻辑总览）

| 章节 | 内容 | 要点 |
|---|---|---|
| 背景与边界 | 已知信息表（已知 → 本设计落点）+ Non-goals | Non-goals 对齐 L0，列出例外裁决 |
| 领域模型总览 | mermaid 图 + 主表/详细表拆分原因 | **拆分原因要写出来**（如读多写少视角） |
| 状态机与业务规则 | 状态码表 + mermaid 状态图 + 编号规则 | 规则逐条编号，便于任务引用 |
| 库表设计 | 摘要 + 指针到 table-design | 明示"冲突以 table-design 为准" |
| 接口契约 | 摘要表 + 关键 DTO 字段 | 详细展开放 api-design |
| 前端边界 | 端职责表 + 信息架构（路由树） | 管理端/用户端分开 |
| 横切与安全 | 接线表（能力 → 本域怎么接） | **只接线、不改口径** |
| 架构落点 | 模块归属图（哪个模块放什么） | 实施时的硬约束 |
| 部署与迁移 | SQL 位置、种子、回滚 | |
| 文档分工 | 本文放什么/不放什么 | 元规则落地 |

## 2. table-design.md（库表契约）

| 章节 | 内容 | 要点 |
|---|---|---|
| **结论清单（先看这个）** | 既有表改不改 / 新增哪几张 / 待裁决点 | **结论先行**，读者 30 秒抓住全貌 |
| 通用原则的系统取值登记 | 对通用设计文档只登记"取值与差异" | **不复制通用条文**（裁剪源模式） |
| 表结构 | 字段/类型/空/默认/说明 + 索引 + 应用层约束 | 审计字段、发号、id 对外 String 等口径引用 L0 |
| 关系一览 | 文字版 ER | 详图放 er-diagram.html |
| **字段裁决说明** | 决策 / 取舍 / 原因 三列表 | **防"优化式破坏"**的核心机制 |
| 种子与迁移 | SQL 落点、种子数据 | |
| **开放问题（唯一清单）** | 编号 + 问题 + 默认取值 | 其他文档只指向本节 |

字段裁决说明示例：

| 决策 | 取舍 | 原因 |
|---|---|---|
| 主表/详细表拆分 | 拆 | 列表不碰正文元数据；大字段只存对象存储 |
| 大字段进对象存储不进 DB | OSS | 大字段拖垮列表查询与备份 |
| 统计字段预留 | 预留 | 本期不做统计；避免后续加列 |

没有这张表，AI 和新同事会把「预留字段」「故意冗余」「刻意拆表」当瑕疵清理掉。

## 3. api-design.md（接口契约）

| 章节 | 内容 | 要点 |
|---|---|---|
| 全局约定 | 前缀/返回体/分页/id 类型/失败语义/幂等/时间格式 | 全部对齐 L0 口径，不复述细节 |
| 错误码语义 | 场景 → 语义枚举名 | 号段分配指针到登记处 |
| 按资源分节 | 接口八元组（见下） | 接口文档的最小完备结构 |
| 接口总表 | # / 方法 / 路径 / 权限 / 主要表 | 一览核对 |
| 典型调用顺序 | 新建/编辑等场景的调用链 | 帮助 AI 理解接口组合关系 |
| 文档分工 | 本文放什么/不放什么 | |

**接口八元组**（每个接口必备）：接口名 / 方法路径 / 权限 / 幂等 / 入参 / 出参 / 接口逻辑 / 使用表。

**接口逻辑的写法**：编号步骤，含校验 → 落库 → 审计 → 失败分支（错误码），并显式标注"**不**碰什么"（如"不改 content_file_id"）——否定性约束对 AI 极其重要。

## 4. 可视化（低效力层）

- `er-diagram.html`、`prototype.html`：浏览器打开，仅作展示与交互参照，**效力低于正文**。
- 原型标注契约锚点（页面元素 → 对应接口/规则），但冲突时以正文为准。
- 实装与原型的差异要在 README 登记（如"hero 统计条未实现，属可选装饰"）。
