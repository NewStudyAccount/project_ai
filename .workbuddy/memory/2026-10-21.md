## blog-portal 图片不显示问题排查

- 排查 `http://localhost:5200/articles/1`（slug=1，文章 id `2026101900000005`）图片不显示。
- **根因**：`frontend/blog-portal/src/utils/markdown.ts` 的 `renderMarkdown()` 是极简实现，只支持标题/粗斜体/行内代码/围栏代码/无序列表/段落，**不支持图片语法 `![alt](url "title")`**，整行被当普通段落输出为 `<p>![...](...)</p>`，永不生成 `<img>`。已用 node 复现确认。
- 数据链路正常：`GET /api/v1/public/articles/1` 返回 200，正文含 MinIO 图片直链 `http://192.168.99.100:9000/blog/d6ea151d-...png`，实测可访问（200 / image/png / 459KB）。
- 次要问题：
  1. 正文用的是 MinIO 直链，未按 `docs/blog-system/api-design.md` §7.1 / business-design §E 约定写 `/api/v1/public/files/{id}`（该接口 302 到稳定公开 URL）。
  2. 封面 `coverFileId="0"` 是无效占位，`/api/v1/public/files/0` 返回 `203030 文件不存在`。
  3. blog-portal 全站无任何 `<img>` 渲染，`coverFileId` 仅在 `api/public.ts` 类型里声明、模板从未使用 → 列表/首页封面同样不显示。
  4. 同一渲染器还缺链接、有序列表、引用、分隔线、表格语法。
- 注意：前端调用路径是 `/api/v1/...`（request.ts baseURL），排错时勿与 `/api/public/...` 混淆（后者 10004 是我方试错路径）。

## 渲染职责归属澄清（设计契约事实）

- 契约现状：`content` 字段**始终是 Markdown 源文**，MD→HTML 在浏览器完成。依据 `docs/blog-system/business-design.md` §E.5「先转义再渲染，不执行原生 HTML；用户端不提供按 HTML 原文展示」+ `api-design.md`「正文一律 Markdown 源文」。
- 后端全项目无任何 HTML 转换逻辑（grep 证实）；`ArticleService.detailPublic()` 仅把 MinIO 里的 .md 原文塞进 VO；`content-url` 仅返回 .md 文件公开 URL。
- 实际存在**两套渲染器**：blog-admin 用 md-editor-v3 自带预览，blog-portal 用自研 `renderMarkdown()` → 编辑器所见非门户所得，是图片 bug 的深层原因。
- 讨论过的路线：A 前端换标准渲染器（markdown-it 级别，契约不动）；B 服务端转 HTML 返回（改契约，需 flexmark + XSS 消毒 + 走 OpenSpec 改文档）；C 后端统一渲染双给 md+html。倾向先 A 后评估 B/C。
- 提醒：接口仅返回 HTML 对 SPA 的 SEO 无帮助（v-html 仍是浏览器注入），SEO 需另做 SSR/预渲染。
